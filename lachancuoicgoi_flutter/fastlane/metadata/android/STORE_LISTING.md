# Store Listing — Lá Chắn Cuộc Gọi

## Vietnamese (vi-VN)

### App name
Lá Chắn Cuộc Gọi

### Short description (80 chars)
Phát hiện lừa đảo cuộc gọi theo thời gian thực bằng AI.

### Full description
Lá Chắn Cuộc Gọi là ứng dụng chống lừa đảo qua cuộc gọi dành cho Android.

**⚠️ Lưu ý quan trọng về nền tảng:**

- **Android:** Bản đầy đủ — nghe nội dung cuộc gọi (Vosk STT), phân tích AI 3 tầng
  (từ khóa → on-device → đám mây), overlay cảnh báo, và chặn số lừa đảo.
- **iOS / Web / Desktop:** Bản xem trước AI (demo). Ứng dụng chạy kịch bản
  cuộc gọi giả để minh họa cách AI phát hiện lừa đảo. **Không** nghe cuộc gọi
  thật, **không** chặn cuộc gọi, **không** truy cập microphone người khác.

**Tính năng chính (Android):**
- 🛡️ Giám sát cuộc gọi theo thời gian thực
- 🎙️ Nhận diện giọng nói Vosk tiếng Việt (offline)
- 🧠 Phân tích AI đa tầng: từ khóa → BERT on-device → Gemini cloud
- 🚨 Cảnh báo trực quan (overlay, rung, chuông) khi phát hiện rủi ro
- 📜 Lịch sử cuộc gọi với phân tích chi tiết
- 🔒 L3 Gemini strip PII trước khi gửi đám mây

**Bảo mật:**
- Hoạt động chính trên thiết bị (on-device). Chỉ gửi transcript (đã strip PII)
  lên đám mây khi cần phân tích L3 (Gemini).
- Không thu thập dữ liệu cá nhân.
- Không bán dữ liệu cho bên thứ ba.

## English (en-US)

### App name
Call Shield

### Short description (80 chars)
Real-time AI-powered scam call detection for Android.

### Full description
Call Shield is an anti-scam call protection app for Android.

**⚠️ Important platform notice:**

- **Android:** Full version — listens to call audio (Vosk STT), runs a 3-tier
  AI pipeline (keyword → on-device → cloud), shows overlay warnings, and can
  block known scam numbers.
- **iOS / Web / Desktop:** AI preview (demo). The app runs scripted mock calls
  to demonstrate how AI detects scams. It does **not** listen to real calls,
  does **not** block calls, and does **not** access anyone's microphone.

### Keywords
scam detection, call screening, fraud prevention, AI, Vietnamese, lừa đảo, chặn số
